# WMCA Data Analytics

## Welcome

This Github organisation contains code repos for analytical projects carried out by the Data Analytics team in the [West Midlands Cancer Alliance](https://wmcanceralliance.nhs.uk/) (WMCA). The Alliance is part of the NHS in England.

Projects contain code, but no data (public or private). You will need to source data in the correct format before you can successfully run any code.

You can contact the team by email at [rwh-tr.wmcadata\@nhs.net](mailto:rwh-tr.wmcadata@nhs.net){.email}
